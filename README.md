# Family System 💜

Aplicación de finanzas personales y del hogar para Karen y Miguel.

## Funciones
- Transacciones (ingresos / gastos), ahorros, deudas y presupuesto mensual
- Notas con adjuntos y notas de voz
- Listas de tareas y calendario financiero
- Portal de pagos de servicios públicos (Soacha, Cundinamarca)
- Alertas de vencimientos y notificaciones
- Sincronización con Google Drive
- PWA instalable en celular y PC, funciona sin conexión

## Tecnología
100% Vanilla JS — sin frameworks ni paso de build. HTML + CSS + JS servidos como sitio estático.

## Privacidad
Los datos financieros se guardan en el navegador de cada dispositivo (localStorage / IndexedDB)
y, opcionalmente, en el Google Drive privado del usuario. El código publicado no contiene datos.
